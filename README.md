## ABOUT THE PROJECT:

I’ve always really liked LEGO, so I wanted to find a way to combine that interest with programming. I came up with the idea of creating an application that could take an image and turn it into something you could build using LEGO bricks.
I used Python to develop the program and Flask to create a website where users can upload their own images. The program processes the image, matches the colors to LEGO colors, and generates building instructions along with a list of the bricks needed.
This project has also given me the opportunity to work more with image processing and web development, which are both areas I wanted to learn more about.

## TOOLS:
- Python
- Flask
- Pillow (PIL)
- HTML/CSS
- CSV
  
## FEATURES:
- Upload images through a web interface
- Process images and match colors to LEGO colors
- Convert image data into LEGO brick information
- Generate step-by-step building instructions
- Create a list of the bricks needed

## IMPROVEMENTS:

I'm still working on improving the accuracy of the LEGO models and making the building instructions easier to follow. I also want to improve the website and eventually give users more options for customizing their models.
